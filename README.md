# Twitter Sentiment Analysis using TF-IDF and Logistic Regression

## 📌 Project Overview

This project implements a **Sentiment Analysis** system for Twitter data using traditional Machine Learning techniques.

The goal is to classify tweets into different sentiment categories based on their textual content.

The project uses:

- Python
- Pandas
- Regular Expressions
- Scikit-learn
- TF-IDF
- Logistic Regression
- Confusion Matrix
- Classification Report

---

## 🎯 Project Goal

The main objective is to build a Machine Learning model that can analyze the text of a tweet and predict its sentiment category.

The general workflow is:

```text
Twitter Dataset
      ↓
Data Cleaning
      ↓
Text Preprocessing
      ↓
TF-IDF Vectorization
      ↓
Train/Test Split
      ↓
Logistic Regression
      ↓
Prediction
      ↓
Model Evaluation
